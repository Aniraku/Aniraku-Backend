# Backend Technology Stack

Aniraku-Backend is a **Go 1.26** service using **Chi v5** for HTTP routing and **Zerolog** for structured logging. Authentication is via **Supabase JWT/JWKS**. Episode metadata is **AniZip (unlimited) ↔ TMDB** via **AniBridge verified mappings + Fribb/anime-lists fallback** (`internal/tmdb/resolver.go` batch `100`, `HasVerifiedTmdbThumbnail`/`IsPublishedTitle`). Streaming is a **pluggable source layer** (fan-out manager, per-module verification, embed passthrough fallback) in `internal/streaming/manager.go`. No Node.js, no Python, no sidecars, one static Go binary. Network safety is `internal/netguard` (`IsPublicIP`, `Control`, `NoRedirects`) + `proxy allowlist` + `uTLS`. Docker is multi-stage `golang:1.26-alpine` → `debian:bookworm-slim`, non-root.
