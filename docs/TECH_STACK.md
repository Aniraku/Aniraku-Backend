# Backend Technology Stack

Aniraku-Backend is a **Go 1.25** service using **Chi v5** for HTTP routing and **Zerolog** for structured logging. Authentication is via **Supabase JWT/JWKS**. Episode metadata is **AniZip (unlimited) ↔ TMDB** via **AniBridge verified mappings + Fribb/anime-lists fallback** (`internal/tmdb/resolver.go` batch `100`, `HasVerifiedTmdbThumbnail`/`IsPublishedTitle`). Streaming is **FlixCloud + Anikoto** (`internal/streaming/manager.go`); FlixCloud decrypts `flixcloud.cc` embeds to direct `hls` `master.m3u8` + `subtitles`/`intro/outro` via **Node 22** `internal/streaming/decrypt.mjs` (WASM + PBKDF2 1000 + AES-256-CBC, one-time token `GET /api/m3u8/{token}`). Network safety is `internal/netguard` (`IsPublicIP`, `Control`, `NoRedirects`) + `proxy allowlist` + `uTLS`. Docker is multi-stage `golang:alpine` → `node:22-alpine`; `cmd/miruro-proxy` Python is disabled.
